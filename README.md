# E-SARABUN-TH

**ระบบสร้างเอกสารราชการและหนังสือสารบรรณอัตโนมัติจากแม่แบบ (Automated Thai Official Document Generator)**
พัฒนาขึ้นตามข้อกำหนดในเอกสารข้อกำหนดระบบ (SRS/SDD) ตามระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526 และที่แก้ไขเพิ่มเติม

---

## 🌟 คุณสมบัติเด่น (Key Features)

1. **สร้างเอกสารราชการมาตรฐาน 100%**:
   - ระยะขอบกระดาษ: ขอบบน 2.5 ซม. (หรือ 3 ซม.), ขอบล่าง 2.0 ซม., ขอบซ้าย 3.0 ซม., ขอบขวา 2.0 ซม.
   - ตราครุฑ: หนังสือภายใน (1.5 ซม.) และหนังสือภายนอก/คำสั่ง (3.0 ซม.)
   - ฟอนต์: `TH Sarabun New` ขนาด 16 pt (หัวข้อ 29 pt หนา) พร้อมระบุ `w:cs` / `w:hAnsi` ป้องกันสระและวรรณยุกต์ซ้อนทับหรือเลื่อน
2. **ระบบแปลงเลขอารบิกเป็นเลขไทยอัตโนมัติ**:
   - สลับเปิด/ปิด แปลงตัวเลข `0-9` เป็น `๐-๙` ได้ทุกช่องในคลิกเดียว
   - รองรับตัวแปลง BahtText (จำนวนเงินตัวอักษรไทย)
3. **ส่งออกได้ทั้ง Word (.docx) และ PDF (.pdf)**:
   - แปลงเป็น PDF ผ่าน Microsoft Word COM Engine ได้ตรงตามรูปแบบ 100%
4. **โหมดสร้างเอกสารเป็นชุด (Batch Mode via Excel)**:
   - ดาวน์โหลดแบบฟอร์ม Excel ที่มีคอลัมน์ตรงกับตัวแปรในแม่แบบ
   - นำเข้า Excel ที่กรอกข้อมูลหลายรายการ แล้วดาวน์โหลดไฟล์เอกสารเป็น `.zip` พร้อมกัน
5. **เครื่องมือตรวจสอบตัวแปรแม่แบบ (Template Inspector)**:
   - อัปโหลดไฟล์ `.docx` ใดๆ เพื่อสแกนค้นหาแท็ก `{{...}}` แบบ Jinja2 อัตโนมัติ
   - เพิ่มแม่แบบใหม่เข้าสู่ระบบได้ทันที
6. **ระบบบันทึกประวัติการสร้างเอกสาร (Audit Log)**:
   - เก็บประวัติเอกสาร เลขที่ เรื่อง วันที่ และรูปแบบไฟล์ผ่าน SQLite ในตัว

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
e-sarabun/
├── main.py                     # FastAPI Core Server & REST API Endpoints
├── utils.py                    # ฟังก์ชันช่วยงานสารบรรณ (แปลงเลขไทย, วันที่ พ.ศ., แปลง PDF, Excel)
├── database.py                 # จัดการฐานข้อมูล SQLite (Audit Log)
├── make_templates.py           # สคริปต์สร้างแม่แบบมาตรฐานตามระเบียบสารบรรณ
├── test_system.py              # ชุดการทดสอบระบบอัตโนมัติ (Automated Tests)
├── start_server.bat            # สคริปต์คลิกเดียวเพื่อเริ่มรันเซิร์ฟเวอร์และเปิดเว็บ
├── templates/                  # โฟลเดอร์เก็บแม่แบบ .docx
│   ├── memo_template.docx      # บันทึกข้อความ (โรงเรียนเกษมสีมาวิทยาคาร)
│   ├── external_template.docx  # หนังสือภายนอก
│   └── order_template.docx     # คำสั่ง / ประกาศ
├── static/                     # ส่วนหน้าบ้าน (Web UI)
│   ├── index.html              # หน้าเว็บหลัก (Tailwind CSS + Vue 3 + Lucide)
│   └── garuda.png              # ไฟล์ตราครุฑความละเอียดสูง
├── output/                     # โฟลเดอร์เก็บไฟล์ผลลัพธ์ (.docx, .pdf, .zip)
└── data/                       # โฟลเดอร์เก็บฐานข้อมูล SQLite
```

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Quick Start)

### เริ่มทำงานทันทีผ่าน Script:
ดับเบิลคลิกที่ไฟล์ **`start_server.bat`**
ระบบจะเปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000` โดยอัตโนมัติ

### หรือรันผ่านคำสั่ง Terminal:
```bash
# รันเซิร์ฟเวอร์
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

## 🔌 รายการ API Endpoints หลัก

- `GET /api/templates`: แสดงรายการแม่แบบทั้งหมดพร้อมตัวแปร
- `POST /api/templates/inspect`: สแกนตัวแปร `{{...}}` จากไฟล์ `.docx`
- `POST /api/templates/upload`: อัปโหลดแม่แบบใหม่เข้าสู่ระบบ
- `POST /api/documents/generate`: สร้างเอกสารเดี่ยว (Word / PDF)
- `GET /api/documents/batch-template`: ดาวน์โหลดฟอร์ม Excel ตามตัวแปรของแม่แบบ
- `POST /api/documents/batch-generate`: สร้างเอกสารเป็นชุดจากไฟล์ Excel (ZIP output)
- `GET /api/history`: เรียกดูประวัติการสร้างเอกสาร
